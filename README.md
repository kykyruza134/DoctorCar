# Doctor Car — статический сайт

Стиль повторяет баннер из группы ВКонтакте: глубокий чёрный фон, красно-синие неоновые диагонали, тонкие линейные иконки, прописные подписи с разрядкой, шрифт Montserrat.
- Шапка: фото в косых панелях, разделённых светящимися красной и синей полосами (как на баннере), под ними ряд из четырёх иконок услуг через неоновые косые разделители.
- Анимации: панели выезжают по очереди, неон мягко пульсирует, блоки появляются при прокрутке, сверху полоса прогресса.
- Механика (форма, анимации появления) — из шаблона сайта 888. Стили Doctor Car лежат в `css/doctorcar.css` поверх `css/style.css`.
- Тема только тёмная: это фирменный стиль баннера.

## Данные
Всё взято из 2ГИС (Excel): 3-й Опытный переулок, 14 (Зональный), телефон +7 (958) 394-39-64, WhatsApp, ВКонтакте, ежедневно 09:00–21:00. Услуги из рубрик: ремонт ходовой части, компьютерная диагностика, сварочные работы, ремонт бензиновых двигателей. Цены — «по запросу». Рейтинга в данных нет, поэтому блока с рейтингом на сайте нет.

На баннере в группе перечислен детейлинг (полировка, керамика, химчистка, бронеплёнка), но в 2ГИС у Doctor Car этих услуг нет, поэтому на сайт они не добавлены. Если сервис их оказывает — добавьте карточки в `index.html`.

На фото размыты госномера машин клиентов.

## Заявка
Только WhatsApp (+7 922 900-47-49): Telegram в данных не указан. Если он появится, впишите ссылку в `telegram` в `js/config.js` — в форме появится выбор.

## Что где менять
- `js/config.js` — WhatsApp, Telegram, часы, на сколько дней вперёд открыта запись.
- `index.html` — тексты, услуги, фото, контакты. Иконки — блок `<symbol>` в начале страницы.
- `css/doctorcar.css` — цвета: `--red`, `--blue`.
- `privacy.html` — реквизиты оператора (выделенные поля).
